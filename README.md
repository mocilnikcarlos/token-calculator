# AI Budget Calculator

Calculadora abierta y gratuita para estimar el presupuesto mensual de uso de IA a partir de operaciones empresariales reales.

## Objetivo

Traducir volumen operativo, llamadas por operación y complejidad del modelo a:

- costo mensual estimado;
- escenarios conservador, probable y exigente;
- costo por operación;
- proyección anual;
- presupuesto recomendado con margen.

## Desarrollo local

```bash
npm install
npm run dev
```

Abrí [http://localhost:3000](http://localhost:3000).

## Aviso

Las cifras son orientativas y dependen de los precios, el diseño de la solución, el uso de caché y el tamaño real de las entradas y salidas.
